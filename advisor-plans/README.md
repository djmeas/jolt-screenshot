## Findings considered and rejected

- **Audit #11 — Monolith page.vue refactor (3,734 lines).** Considered as
  a plan. Rejected because: (a) it has no user-visible bug, (b) the
  refactor is large enough to deserve its own dedicated plan + sign-off
  cycle, and (c) several other plans in this index implicitly depend on
  keeping the monolith structure. Recommend opening a separate plan file
  (`advisor-plans/009-monolith-refactor.md`) when the team has bandwidth.
- **Audit #8 — Text-input blur can call commitText unexpectedly.**
  Inspected the `commitText` logic at lines 1379–1397 and `textInputValue`
  state. After Escape clears `textInputValue.value = ''`, the empty string
  fails `text.trim()` so `commitText` is a no-op. The path is already
  defensively coded; no fix needed.
- **Audit #10 — body.style.overflow leak on unmount with help open.**
  The watcher at lines 2473–2497 runs its cleanup the next time `showHelp`
  changes; navigating away doesn't unmount the help modal — it teleports
  to `body` and stays until the page navigates, at which point the entire
  JS heap is destroyed anyway. No leak worth fixing.
- **Audit #12 — 350-line emoji list as a literal in the script block.**
  Stylistic, not functional. Defer to a future plan that bundles
  data-extraction across the codebase.
- **Audit #13 — `saved.annotations as Annotation[]` cast.**
  Today there is no migration path and `JSON.parse` is wrapped in
  try/catch. The blast radius is "renders nothing" rather than "crashes."
  A future schema-version bump plan could harden this; not worth a plan
  today.
- **Audit #14 — `storageBytes = total × 2` heuristic.** Cosmetic
  inaccuracy in the Saves panel footer. Defer to a future polish pass.
- **Audit direction #1 — Download as PNG.** Good idea, but adds UI work
  and clipboard isn't broken. Out of scope for a code-health audit.
- **Audit direction #2 — Tap-to-cycle emoji.** Product call, not a bug.
- **Audit direction #3 — Server-rendered OG share image.** Big scope
  (backend, KV, route table, sharing UX). Out of scope.
